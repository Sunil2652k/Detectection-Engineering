# Detection Repo

This repository contains detection engineering assets and Python utilities for threat hunting and Sigma-based detection content.

## Quick start

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Structure

- `src/` - Python utilities and ingestion scripts
- `rules/` - Sigma rules and detection files
- `tests/` - validation and smoke tests
- `docs/` - project documentation
