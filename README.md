# Detection Repo

This repository contains detection engineering assets and Python utilities for threat hunting and Sigma-based detection content.

## Quick start

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Structure

- `src/` - Python utilities and detection scripts
- `rules/` - Sigma rules and detections
- `tests/` - validation tests
- `docs/` - documentation
